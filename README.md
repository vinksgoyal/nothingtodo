`nothingtodo` is a local-first Python 3.11+ project scaffold for turning unstructured input into actionable tasks using OCR, text-to-speech, and locally hosted language models; business logic will be added in a subsequent step.

## Setup

```sh
make install
ollama pull llama3.2:3b
ollama pull qwen2.5:7b
sudo apt install tesseract-ocr poppler-utils
```
